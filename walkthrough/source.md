# Device tree source and Zephyr overlays

- Right-click a .dts, .dtsi or .overlay file and pick Open DeviceTree Viewer, or use the tree icon at the top right of its text editor.
- Once the extension runs in the window, the DeviceTree view in the Explorer lists the nodes of the active .dts, .dtsi or .overlay file. Click a node to go to its line.
- #include lines are listed, macros stay as written, and `&label { ... };` blocks from other files show at the end of the tree.
